1. EXECUTIVE SUMMARY & WHAT IS THIS PROJECT?
================================================================================
AgenticMarketer is an enterprise-ready, full-stack, autonomous multi-agent
marketing intelligence and content generation platform. Powered by Google Gemini
AI models and Hugging Face visual diffusion models (FLUX.1-schnell / SDXL),
AgenticMarketer orchestrates a cooperative swarm of specialized artificial
intelligence agents to transform raw brand guidelines, product documentation, and
marketing goals into complete, production-ready, omnichannel campaigns.

Instead of a generic single-prompt chatbot, AgenticMarketer operates like an
elite growth marketing agency. When given a high-level goal (for example:
"Launch our new AI analytics tool to European B2B SaaS founders with an
educational, high-authority tone"), the system activates six coordinated agents
that retrieve internal company knowledge, conduct live market and competitor
research, draft 12 channel-tailored copy formats (including a Universal Master Copy
and Meta Threads), generate photorealistic multimodal visual banners, score SEO/
readability metrics, and dispatch finished posts to 15 connected social networks.


================================================================================
2. PURPOSE & REAL-WORLD PROBLEM IT SOLVES
================================================================================
Modern marketing teams and growth-stage companies face several bottlenecks:
- Brand Inconsistency: Generic AI models hallucinate product features or fail to
  adhere to strict brand guidelines, company voice, or technical specifications.
- Content Fragmentation: Writing separate, optimized copy for LinkedIn, X (Twitter),
  Meta Threads, Instagram, Facebook, Reddit, Medium, Dev.to, WordPress, Discord,
  Slack, YouTube, and TikTok takes hours of manual adaptation per campaign.
- Lack of Deep Research: Most social tools do not cross-reference current web
  trends, competitor angles, or viral hooks in real-time.
- Plain Text Limitations: Marketers need feasible, multimodal creative assets—not
  just raw text—with photorealistic imagery, visual mockups, and real platform previews.
- Multi-Tool Chaos: Teams currently juggle separate subscriptions for copy
  generation, SEO scoring, AI image design, brand document wikis, and social
  media schedulers.

AgenticMarketer solves this by unifying the entire pipeline into one continuous,
automated workflow grounded in the company's own verified documents.

3. HOW IT WORKS (END-TO-END WORKFLOW)
================================================================================
The workflow follows a 4-stage lifecycle:

STAGE 1: KNOWLEDGE INGESTION (RAG)
  1. The user uploads company documents (PDFs, DOCX, TXT, Markdown) via the
     Knowledge Base page or attaches files directly on the Dashboard.
  2. The backend extracts clean text, splits it into semantic chunks with overlap,
     and computes vector embeddings using Google's embedding models
     (with a local TF-IDF cosine fallback).
  3. Chunk metadata, text, and vector embeddings are saved to the local data store.

STAGE 2: CAMPAIGN CONFIGURATION
  1. The marketer accesses the Dashboard.
  2. The user configures:
     - Campaign Goal & Directive (e.g., "Feature announcement for v2.0")
     - Target Audience (e.g., "Enterprise DevOps Engineers")
     - Tone of Voice (e.g., "Authoritative, technical, inspiring")
     - Content Type & Target Channels (LinkedIn, Twitter/X, Threads, Meta, Reddit, etc.)
     - Reference files attached specifically to this campaign run.

STAGE 3: AUTONOMOUS MULTI-AGENT PIPELINE
  When the user clicks "Launch 6-Agent Swarm", the backend pipeline triggers the 6
  specialized agents in real-time sequence. Each agent takes the accumulated context
  and outputs from previous agents, enriches the data, and passes it forward.

STAGE 4: REVIEW, ASSET INSPECTION & OMNICHANNEL BROADCAST
  1. The marketer views real-time agent output in the Clean Studio view.
  2. The system presents:
     - Visual Creative Showcase featuring the Hugging Face FLUX.1 rendered image.
     - 12 Channel-Tailored Cards with interactive social feed mockups (Threads, LinkedIn, Ads).
     - Universal Master Copy ("Post Anywhere") for versatile cross-platform posting.
     - Live SEO & readability audit breakdown (Flesch-Kincaid, keyword density).
  3. The marketer can copy single sections or click "Broadcast Campaign" to dispatch
     content to 15 supported platforms and outbound webhooks.

4. THE 6 AUTONOMOUS AI AGENTS EXPLAINED
================================================================================
AgenticMarketer's brain is divided into 6 specialized personas:

1. DOCUMENT INGESTION & BRAND RETRIEVAL AGENT
   - Role: The Librarian & Brand Guardian.
   - Function: Analyzes the campaign goal, queries the vector knowledge base for
     relevant brand chunks, extracts brand tone guidelines, core value
     propositions, and disallowed claims.
   - Output: Grounded brand context packet injected into subsequent agent prompts.

2. MARKET RESEARCH & COMPETITOR INTELLIGENCE AGENT
   - Role: The Growth Strategist & Market Analyst.
   - Function: Performs live web searches (via DuckDuckGo) for real-time market
     developments, viral industry angles, customer pain points, and competitor
     positioning.
   - Output: Strategic research brief containing top hooks, target keyword themes,
     and competitive differentiation angles.

3. CREATIVE COPYWRITER & MULTI-CHANNEL ADAPTATION AGENT
   - Role: The Master Copywriter & Creative Strategist.
   - Function: Takes grounded brand documents and live market research to craft
     tailor-made posts across 12 distinct platforms:
     * 🌟 Universal Master Copy (Post Anywhere)
     * 🎯 Hook & Headline Variations (Contrarian, ROI, Proof)
     * 💼 LinkedIn Thought Leadership (Framework + Hashtags)
     * 🧵 X (Twitter) Auto-Thread (3-part with char limits)
     * 🤖 Reddit Discussion (Community-first formatting)
     * 📝 Medium / Dev.to / Blog Article (Long-form editorial)
     * 🧵 Meta Threads (Conversational microblog under 500 chars)
     * 🎥 Short-Form Video Script (Reels / TikTok / Shorts)
     * 💬 Community Announcement (Discord / Slack)
     * 📧 B2B Outbound Cold Email (High-open subject + pitch)
     * 📱 Meta & Paid Social Ad Creative (Primary, Headline, Description)
     * 🎨 Multimodal Visual Generation Prompt
   - Output: Complete, conversion-engineered omnichannel marketing bundle.

4. MULTIMODAL VISUAL GENERATION AGENT
   - Role: The Creative Director & AI Visual Designer.
   - Function: Synthesizes campaign theme into a photorealistic commercial photography
     prompt and routes generation to Hugging Face Diffusion (FLUX.1-schnell / SDXL)
     with secondary failover to Gemini Image models and crisp typography overlay.
   - Output: Image URL, multimodal creative banner, and downloadable visual assets.

5. SEO, READABILITY & MARKETING COMPLIANCE AGENT
   - Role: The Quality Control & SEO Specialist.
   - Function: Performs mathematical text analysis on generated copy using textstat:
     * Flesch-Kincaid Grade Level & Reading Ease score.
     * Keyword density and primary/secondary keyword placements.
     * Social length limit checks (flags if Twitter post > 280 chars, Threads > 500 chars).
     * Compliance review against brand safety rules.
   - Output: Numerical health score (0-100), audit badges, and recommendations.

6. OMNICHANNEL SOCIAL PUBLISHER AGENT
   - Role: The Distribution Manager.
   - Function: Interfaces with 15 social media APIs and webhook endpoints:
     LinkedIn, X/Twitter, Meta Facebook, Instagram, Meta Threads, Reddit, YouTube,
     TikTok, Pinterest, Medium, Dev.to, WordPress, Discord, Slack, and Universal Webhook.
   - Output: Dispatch status, platform receipt IDs, and timestamped audit logs.

6. MULTIMODAL VISUAL ENGINE (HUGGING FACE FLUX.1 & GEMINI)
================================================================================
AgenticMarketer features a dedicated multimodal visual creative pipeline:

1. Primary Engine: Hugging Face Diffusion (`black-forest-labs/FLUX.1-schnell` / `SDXL`)
   - Dual Invocation: Queries via `huggingface_hub.InferenceClient` with automatic
     fallback to direct HTTP REST API calls.
   - Generates photorealistic 1024x1024 commercial campaign visuals.

2. Secondary / Fallback: Google Gemini Generative Vision (`gemini-3-pro-image`)
   - Engaged if HF rate limits are reached or as an alternative endpoint.

3. Vector Typography Compositing:
   - High-contrast TrueType headline text overlays composited onto generated images.

4. Dashboard Creative Showcase:
   - Preview campaign visuals right alongside the copy in the Clean Studio view.
   - 1-click Download, Enlarge, and Visual Studio prompt editor.

8. VECTOR RETRIEVAL (RAG) & KNOWLEDGE BASE ENGINE
================================================================================
The Retrieval-Augmented Generation (RAG) system is built inside:
`backend/app/rag/vector_store.py`

Key technical highlights:
1. Multi-Format Parsing:
   - PDF files via 'pypdf'
   - Microsoft Word documents via 'python-docx'
   - Plain text (.txt) and Markdown (.md) via standard UTF-8 parsing
2. Overlapping Semantic Chunks:
   - Configurable chunk size (default: 500 characters)
   - Overlap window (default: 80 characters) to prevent context loss across boundaries.
3. Hybrid Dual-Layer Vector Search:
   - Primary: Computes dense vector embeddings using Google's embedding models.
     Query similarity is computed using vectorized numpy cosine similarity.
   - Fallback: If external network is offline, the engine activates a built-in
     term-frequency cosine vectorizer so search and retrieval never crash.

12. API REFERENCE & ROUTERS
================================================================================

SYSTEM & DIAGNOSTICS:
- GET  /api/health   -> { "status": "healthy", "version": "1.0.0", "active_agents": 6 }
- GET  /api/stats    -> { "total_documents": int, "total_chunks": int, "tokens_used": int }

AUTHENTICATION ROUTER (/api/auth):
- POST /api/auth/register           -> Creates user account
- POST /api/auth/login              -> Authenticates and returns JWT bearer token
- GET  /api/auth/me                 -> Current profile
- GET  /api/auth/users              -> List team members (Leader/Admin)
- PUT  /api/auth/users/{id}/role    -> Updates user role

KNOWLEDGE & RAG ROUTER (/api/rag):
- POST /api/rag/upload              -> Ingests PDF, DOCX, TXT into semantic vector store
- GET  /api/rag/documents           -> Lists all indexed documents
- DELETE /api/rag/documents/{name}  -> Deletes document and cleans vector chunks
- POST /api/rag/query               -> Semantic vector search query

SWARM PIPELINE ROUTER (/api/swarm):
- POST /api/swarm/run-sync          -> Executes full 6-agent campaign swarm synchronously
- POST /api/swarm/launch            -> Asynchronously launches swarm
- GET  /api/swarm/stream/{run_id}   -> SSE real-time telemetry stream
- GET  /api/swarm/images/{filename} -> Serves AI-generated image assets

PUBLISHING ROUTER (/api/publish):
- POST /api/publish/broadcast       -> Broadcasts campaign copy across 15 connected platforms
- GET  /api/publish/history         -> Audit log of all broadcasts with timestamps

15. HOW TO SET UP AND RUN LOCALLY
================================================================================

PREREQUISITES:
- Python 3.10+ installed
- Node.js 18+ and npm installed

STEP 1: CONFIGURE ENVIRONMENT
1. Ensure `.env` exists in the project root with your API keys.

STEP 2: START THE BACKEND SERVICE
1. Open a terminal in the project root:
   .venv\Scripts\activate
2. Start the FastAPI server:
   uvicorn backend.app.main:app --reload --port 8000
3. API is live at http://localhost:8000 (Swagger docs at /docs)

STEP 3: START THE FRONTEND SERVICE
1. Open a second terminal window in `frontend/`:
   npm run dev
2. Navigate to http://localhost:3000

STEP 4: LOG IN AND TEST
1. Click the "Demo Leader" button or log in with mann@company.com / admin123.
2. Head to "Dashboard", type your campaign goal, and click "Launch 6-Agent Swarm".
